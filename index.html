Сервисы

VPN-сервис с подписками и платежами

Работающий MVP · закрытый репозиторий · 660+ коммитов

Коммерческий сервис на базе панели Remnawave: пользователь оформляет подписку в Telegram-боте, оплачивает её и автоматически получает доступ.

  • Backend с тарифами, подписками, платежами, напоминаниями и блокировкой доступа при неоплате.
  • Заменяемые слои: платёжный провайдер и VPN-панель подключены через тонкие интерфейсы.
  • PostgreSQL как источник истины, миграции, фоновые задания и журнал аудита.
  • Мониторинг нод в Prometheus и Grafana, автоматизированные тесты транспортов, в том числе на Android.
  • TypeScript

VPN-сервис с собственным control plane

В разработке · закрытый репозиторий · 410+ коммитов

Следующая версия сервиса, которая не зависит от сторонней панели: собственный backend управления доступом и нативные клиенты.

  • Модульный backend на Go, обмен между модулями по схеме outbox/inbox.
  • Android-клиент на Kotlin, версионируемые API-контракты.
  • Архитектурные решения ведутся как ADR; описаны модель угроз, карта данных, выпуск и откат релизов.

Videocombain — кросс-публикация видео

Работающий MVP · закрытый репозиторий · 240+ коммитов

Сервис отслеживает новые видео на YouTube и Twitch и публикует их в VK Видео с названием, описанием, обложкой и таймкодами.

  • Веб-панель с источниками, очередью публикаций и ручной модерацией.
  • Тематический фильтр по ключевым словам, автопубликация или подтверждение в панели.
  • Таймкоды формируются из расшифровки речи (Whisper) и LLM.
  • Редактор пресетов для нарезки вертикальных клипов.
  • Python

Video Summarizer — пересказ видео

MVP · открытый репозиторий

Приложение делает структурированный пересказ видео по ссылке (VK, YouTube, Twitch, Kick) или из локального файла.

  • Пайплайн: yt-dlp/ffmpeg → WhisperX с разделением по спикерам → разбиение на части → LLM.
  • Асинхронные задания с отслеживанием статуса, запуск с любого шага, остановка в процессе.
  • Журнал аудита и диагностический режим.
  • React
  • Vite
  • Node.js
  • Express
  • WhisperX
  • LLM
